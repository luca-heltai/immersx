# ImmersX documentation

ImmersX is a deal.II-based framework for embedded and mixed-dimensional
finite-element simulation. The documentation is organized around the task you
want to complete.

## Find your way around

- [Get started](getting-started/index): install the prerequisites, build
  ImmersX, and run your first Poisson example.
- [Follow a tutorial](tutorials/index): learn the framework through a sequence
  of runnable simulations.
- [Find a how-to](how-to/index): configure applications, boundary conditions,
  reduced coupling, and output.
- [Understand the concepts](concepts/index): read the mathematical and
  architectural ideas behind the examples.
- [Look up the reference](reference/index): check executable capabilities,
  parameter groups, and the generated C++ API.
- [Contribute](developer/index): build, test, document, and extend the project.

The [API reference](api/library_root) is generated from the public
headers. The [mathematical background](concepts/mathematical-background) and
[architecture concepts](concepts/architecture) explain the notation and
ownership boundaries used throughout the documentation.
